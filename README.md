# Народження Всесвіту

Кінематографічна інтерактивна візуалізація: від Великого вибуху до Сонячної системи.
Vite + TypeScript + Three.js (власні GLSL-шейдери), pmndrs/postprocessing, GSAP, Web Audio API.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # статичний білд у dist/ (Vercel / Netlify)
npm run preview  # перегляд продакшн-білду
```

Netlify підхоплює `netlify.toml`; Vercel розпізнає Vite автоматично (output: `dist`).

Прев'ю для соцмереж (`public/og.jpg`) отримує абсолютну адресу автоматично на Netlify (`URL`) і Vercel
(`VERCEL_PROJECT_PRODUCTION_URL`). На іншому хостингу задайте `SITE_URL=https://ваш-домен/` перед `npm run build`.

## Керування

| Клавіша | Дія |
|---|---|
| Клік / Enter | почати (на стартовому екрані) |
| Space | пауза |
| M | звук увімк./вимк. |
| S | пропустити до Сонячної системи |
| R | почати спочатку |
| B | назад у часі: перемотати до Великого вибуху й переглянути знову (у фіналі) |
| Клік на шкалі часу | перейти до будь-якої епохи |
| Коліщатко за межу / Z · X | «Космічний зум»: Сонячна система → «Вояджер-1» і геліопауза → сусідні зорі → Чумацький Шлях → Місцева група → космічна павутина → спостережуваний Всесвіт і назад |
| H | «Додому»: плавний переліт назад через усі рівні зуму до Сонячної системи |
| T | екскурсія планетами (також стартує сама після 45 с бездіяльності) |
| V | справжні розміри: Сонце і вісім планет в одному масштабі |
| G | «Політ»: Сонце мчить крізь Галактику, планети тягнуться за ним по спіралях (швидкість Сонця в анімації зменшено, щоб витки було видно). На рівнях зуму: рух до сонячного апексу, обертання Галактики, зближення з Андромедою, течія до Великого Атрактора, диполь реліктового світла |
| N | «Для допитливих»: меню коротких наукових сцен поза фільмом — 1 «Перші 3 хвилини» (нуклеосинтез), 2 «Наднова», 3 «Народження Місяця», 4 «Пульсар», 5 «Злиття чорних дір» (гравітаційні хвилі й «chirp»), 6 «Майбутнє Сонця» (червоний гігант, планетарна туманність, білий карлик), 7 «TRAPPIST-1» (сім планет біля червоного карлика, в масштабі); після сцени — повернення до Сонячної системи (Esc або N — раніше) |
| P | фото-режим: сховати весь інтерфейс |
| C | зберегти кадр у PNG (у фото-режимі) |
| E | затемнення: спершу сонячне (тінь Місяця на Землі), натисніть ще раз — місячне (Місяць червоніє в тіні Землі) |
| J | комета зблизька: ядро, струмені газу, пиловий і іонний хвости (Esc — назад) |
| K | сузір'я: контури Оріона, Великого Воза, Кассіопеї, Південного Хреста, Лебедя, Скорпіона й імена яскравих зір (зорі розміщені за справжніми координатами) |
| Клік на кротову нору біля Сатурна | пасхалка за «Інтерстеларом»: прохід крізь нору (промені простежені крізь кротову нору Елліса, як у фільмі) в іншу галактику — систему Гаргантюа (чорна діра, що обертається, з трасуванням променів) з планетами Міллер (океан із припливними хвилями), Манна (лід і замерзлі хмари) й Едмундс на орбітах і кораблем «Ендюранс», до якого, коли до нього підлітаєш, пристиковується «Рейнджер». Камеру можна вільно обертати й наближати, клік на планету чи діру — політ до неї й картка; перемикач унизу ліворуч (або F) показує діру «як у кіно» (кругла тінь, рівне золоте світло, як у фільмі) чи «як насправді» (обертання майже граничне, ефект Доплера на повну, гарячіші кольори); рот нори там або Esc — назад крізь нору до Сатурна |
| Esc | повернутися з картки планети / вийти з фото-режиму |
| D | дебаг-панель (тільки `npm run dev`) |

## Структура

```
src/
  main.ts            детекція пристрою → заглушка або динамічний import застосунку
  device.ts, stub.ts заглушка для мобільних / без WebGL2 (без Three.js, ~5 КБ)
  config.ts          усі налаштування (частинки, bloom, кольори, тривалості)
  app/App.ts         рендерер, цикл, гарячі клавіші, пауза, пропуск/рестарт
  app/Director.ts    єдиний GSAP master timeline: сцени, підписи, звук, космічний годинник
  app/SceneManager   enter() / update(dt) / exit() для кожної сцени
  app/Post.ts        Bloom, film grain, віньєтка, ACES; chromatic aberration лише у вибуху
  app/PerfMonitor    fps < 45 протягом 2 с → менше частинок, слабший bloom, нижчий DPR
  scenes/            0 Singularity · 1 BigBang · 2 Plasma · 3 Cosmos · 4 Approach · 5 Solar · CosmicZoom
                     «Для допитливих» (поза фільмом, окремий чанк scenes/optional, вантажиться у фоні):
                     Nucleosynthesis · Supernova · MoonBirth · Pulsar · Merger · SunFuture · Trappist · Gargantua
  scenes/solar/      будова Сонячної системи: sun (поверхня, петлі, корона), planet (шейдер планет),
                     atmosphere (атмосфери, небо Землі, вулкани Іо), belts (пояси, сонячний вітер, брили,
                     уламки кілець Сатурна), common (спільні шейдери й типи)
  scenes/wormhole.ts кротова нора Елліса (промені через еліптичні інтеграли) і два небеса
  scenes/Gargantua   пасхалка: система Гаргантюа — діра Керра (трасування в метриці Керра),
                     планети з лінзуванням, корабель-кільце, прохід крізь нору туди й назад
  data/planets.ts    дані планет і «зручний» масштаб
  i18n/              мова інтерфейсу: tr() і англійський словник (ключ — український текст)
  audio/AudioEngine  синтезований звук (без аудіофайлів)
  debug/DebugPanel   lil-gui, «Експорт налаштувань» копіює JSON для config.ts
  debug/selfTest     самотест усіх сцен (лише npm run dev)
```

**Мова.** Українська за замовчуванням; англійська — за адресою `/en` (збірка робить `en.html` з англійськими мета-тегами, `hreflang`, `sitemap.xml` і `robots.txt`; у режимі розробки — `?lang=en`). Кнопка «EN» / «УК» у панелі перемикає між ними, вибір запам’ятовується. Новий текст на екрані додається до `src/i18n/en.ts` — у режимі розробки відсутній переклад видно в консолі.

**Посилання на сцену.** `?scene=solar` — одразу Сонячна система; `?scene=gargantua`, `?scene=pulsar`, `?scene=merger` тощо — одразу сцена «Для допитливих» (адреса оновлюється сама, тож її можна просто скопіювати).

**Фото.** Кнопка з фотоапаратом (або P) ховає інтерфейс; «Зберегти кадр» (або C) завантажує PNG.

**Самотест.** У `npm run dev` відкрийте сторінку з `?selftest` або викличте `__selfTest()` у консолі: застосунок пройде фільм, усі рівні зуму, сцени «Для допитливих» і Гаргантюа туди й назад, перевіряючи помилки шейдерів, помилки в консолі й чорні кадри. Звіт — у консолі й на сторінці.

Кількість частинок змінюється в дебаг-панелі й застосовується після «Почати спочатку».
`prefers-reduced-motion`: без тремтіння камери, м’які спалахи.

## Текстури

На сайті вказано авторство текстур (рядок унизу праворуч), як того вимагає CC BY 4.0.

`public/textures/earth/` — карти Землі (поверхня, нічні вогні, маска океанів, хмари) з прикладів [three.js](https://github.com/mrdoob/three.js/tree/r160/examples/textures/planets), створені на основі зображень NASA Blue Marble / Black Marble (суспільне надбання). Поки вони вантажаться, Земля малюється процедурно.

`public/textures/planets/` — карти Меркурія, Венери (хмарний шар), Марса, Юпітера, Сатурна та його кілець, Урана, Нептуна, Місяця, Церери й Еріди: © [Solar System Scope](https://www.solarsystemscope.com/textures/), ліцензія [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Карти перестиснуто: газові гіганти, Марс і Венера у WebP, кратерні тіла лишаються в JPEG (якість 0,86); Плутон і супутники Юпітера та Сатурна лишаються процедурними.

`public/textures/sky/milky_way_4k.webp` — панорама неба з Чумацьким Шляхом (галактичні координати), © [Solar System Scope](https://www.solarsystemscope.com/textures/), CC BY 4.0, зменшена з 8K до 4096×2048 і перестиснута у WebP; поки її немає, смуга малюється процедурно.
